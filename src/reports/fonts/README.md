# Report font

`NotoSansTamil.ttf` is the unmodified variable Noto Sans Tamil font from
https://github.com/google/fonts/tree/main/ofl/notosanstamil (Noto Sans Tamil v2.004).
It covers Latin and Tamil text for PDF report cells. The SIL Open Font License
and copyright notice are retained in `OFL.txt`. PDFKit embeds the glyphs used by
each report; generation does not fetch fonts from the network.
